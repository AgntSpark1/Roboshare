# RoboShare 运营控制台交互原型（演示）

与投资者 DApp（`apps/web-preview`）分开部署的管理员站点原型。直接用浏览器打开 `index.html`。

- 登录：钱包签名（SIWE，核验链上角色）+ 员工账户动态验证码（TOTP）。
- 模块：总览/待办、车辆项目（登记、审核、生命周期）、募集管理（托管、结算、退款）、财务报告（审核人 ≠ 提交人、驳回需原因）、分配批次（按持有人预览毛额/档位/净额/尾差）、Safe 2/3 多签 + 24h 时间锁、投资者资格（冻结保留分配权）、角色权限、对账与监控、紧急暂停（输入 PAUSE 确认）、审计日志。
- 顶部可切换身份（运营方 / 审核人 / 治理签名人 / 守护者 / 合规），无权限的操作会置灰并说明原因。

**所有数据、地址和交易均为示例。** 不连接真实钱包，不发送任何交易。
