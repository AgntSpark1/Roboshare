# RoboShare DApp 交互原型（演示）

单文件静态原型，用于在正式的 `apps/web`（Next.js + wagmi/viem）实现之前确认页面结构、交互流程与视觉方向。

- 直接用浏览器打开 `index.html` 即可，无需构建。
- 首页为 three.js 3D 场景（激光雷达点云、光轨、线框城市），另有车队实时调度动画。
- 页面：首页、车辆项目列表、项目详情与认购、我的资产（领取分配、撤销授权）、风险披露。运营后台是独立站点，见 `apps/admin-preview`。
- 认购流程按 D-23：首次认购先授权 USDT（默认不限额，授权前有风险提示），之后按份数一笔交易认购。
- 费率档位、分配公式与 `docs/TOKENOMICS.md` 一致（毛额向下取整，分成向下取整）。

**所有项目、车辆、收益、地址和交易哈希均为示例数据。** 不连接真实钱包，不发送任何交易。RoboShare 与 Tesla 不存在任何合作关系。
