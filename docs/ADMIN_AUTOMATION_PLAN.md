# 运营自动化与管理后台升级计划

2026-10-11 · 线程「自动化与管理后台升级」· 仅测试网，主网另行审批

目标：日常运营不再需要在 Mac 上开 Claude。能自动的交给后台（worker）自动跑；必须由有权限的钱包签名的，在管理后台一键准备好，用手机钱包签名即可。

原则：服务器不保存任何有合约权限的私钥（只付 gas、没有权限的钱包可以）。要在服务器上放有权限的私钥，必须先由 Charlene 明确同意。

## 现状

后台已有：登记项目、核验、开启募集提案、结算、运营报告提交/审核、分配批次提议/批准、邀请奖励根发布、紧急暂停交易、角色/审计/对账查看。

缺口：
1. 所有治理（Safe 2/3）操作只生成 calldata，要复制到 Safe 网页去签，BSC 测试网的 Safe 网页还不一定支持。
2. 投资者资格（白名单）在后台没有页面，只能在 Mac 上跑脚本。
3. 运营/审核/合规/Safe 的私钥都在 Mac 上，手机钱包没有这些角色。

## 操作清单与处理方式

| 操作 | 频率 | 处理 | 批次 |
|---|---|---|---|
| 募集满额/到期达标后结算 | 每个项目 | 自动（公开结算 + 付 gas 钱包，线程「测试网钱包和部署」在做） | 进行中 |
| 募集失败退款 | 少见 | 已是公开操作，投资者自己领；后台加一键“标记失败” | 2 |
| 治理 Safe 操作（开募集、投运、排除认购人、改角色、改参数） | 每个项目数次 | 后台一键：直接在后台用 Safe owner 钱包确认，凑够 2 人后一键执行，不用再去 Safe 网页 | **1** |
| 投资者资格（白名单）开通/撤销 | 每个新投资者 | 后台一键：列出已登录钱包，勾选后合规钱包一次签名批量开通 | **1** |
| 后台待办提醒 | 持续 | 首页待办集中显示待签 Safe 交易和待开通投资者 | **1** |
| 登记新车辆项目、核验 | 每个项目 | 已是后台一键 | — |
| 运营报告提交与审核 | 每期 | 已是后台一键（两人分工） | — |
| 收益分配批次 | 每期 | 报告批准后自动生成分配预览，运营一键提议，审核一键批准 | 2 |
| 邀请奖励 Merkle 根 | 每期 | 后台自动计算，运营一键发布（推荐奖励开关默认关闭） | 2 |
| 手续费提取、资金账户授权 | 每期 | 后台一键准备交易 | 2 |
| 紧急暂停 | 紧急 | 已能生成交易；改为后台直接用暂停钱包签名 | 2 |
| 通知（新认购、满额、待审核） | 持续 | 邮件或 Telegram 推送给运营 | 2 |
| 测试网 tUSDT 发放 | 测试期 | 后台一键 | 2 |
| 资格自动开通（不经人工） | 每个新投资者 | 需要服务器持有合规私钥，**需 Charlene 同意**；主网必须接真实 KYC | 3（待定） |

## 一次性准备（需要 Charlene 决定）

要在手机上完成以上操作，测试网的角色要交给她手机里的钱包：
- 给她的钱包授予运营、审核、合规、暂停角色，并登记为后台人员（绑定验证器 App）。
- Safe 3 个 owner 中至少 2 个换成她自己控制的钱包（可以是同一个钱包 App 里的两个账户）。
- 这一步需要最后一次在 Mac 上用现有私钥执行。

注意：分配批次的提议人不能自己批准，所以运营和审核最好是两个不同的钱包账户。
