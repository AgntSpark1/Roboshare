# RoboShare 提前退出（转让市场）设计

状态：2026-10-11 Charlene 选定“两者结合”。合约 `ShareMarket` 已实现，前端待做。主网前需律师确认。

## 1. 结论

- 投资者想提前拿回本金时，在平台的**转让市场**挂单卖出自己的单位，由其他合格投资者用 USDT 买走。
- 平台**可以**用自己的合格钱包买入挂单（兜底），但这是平台自愿的普通购买：没有回购义务、没有保底价、没有承诺时间。对外文案不得出现“保本”“随时赎回”“平台回购”等字样。
- 平台不出资做任何赎回池，合约里也没有平台专用的回购入口。

## 2. 为什么不做“平台回收再出售”

- 资金压力：平台需要长期备着 USDT 接盘，集中退出时可能接不住。
- 合规风险：“随时找平台拿回本金”容易被认定为保本或刚性兑付承诺，可能改变产品的法律性质。
- 两者结合后，平台仍可在合适时买入，但保留选择权。

## 3. 合约 `ShareMarket`（`contracts/src/market/ShareMarket.sol`）

| 项目 | 规则 |
| --- | --- |
| 挂单 | `list(projectId, units, pricePerUnit, expiresAt)`。卖家先对市场合约 `approve` 份额代币。只能挂 AssetRegistry 中已关联代币的项目 |
| 改单 / 撤单 | 只有卖家本人。暂停期间仍可撤单 |
| 购买 | `buy(listingId, units, maxPricePerUnit)`，可部分成交。USDT 直接从买家到卖家，份额直接从卖家到买家，同一笔交易完成 |
| 资金托管 | 无。合约从不持有 USDT 或份额，没有提款函数 |
| 手续费 | 无（D-8：平台只收分配环节的分级手续费） |
| 价格 | 卖家自定。买家的 `maxPricePerUnit` 防止成交前被改价 |
| 转让限制 | 全部由份额代币执行：买家须合格且类别获准、卖家未被冻结、项目处于 FUNDED / ACTIVE、代币未暂停 |
| 治理 | 管理员 = 时间锁（2/3 多签 + 24h）。PAUSER 可暂停，解除暂停需治理 |
| 查询 | `fillable(listingId)` 返回考虑到期、卖家余额和授权后当前可买数量 |

挂单不锁定份额：卖家在挂单后转走份额，购买会失败，前端以 `fillable` 显示真实可买数量。

## 4. 收益归属

分配按报告期末快照余额计算（D-7）。成交前已经快照的分配归卖家，之后的归买家。前端在购买页提示这一点。

## 5. 部署

`contracts/script/DeployShareMarket.s.sol`，在现有部署上追加，需要环境变量 `ASSET_REGISTRY`、`PAYMENT_TOKEN`、`TIMELOCK`、`PAUSER`。部署者不持有任何角色。测试网在 Charlene 的 Mac 上执行。
